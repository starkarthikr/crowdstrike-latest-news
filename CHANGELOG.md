# Changelog

All notable changes to the CrowdStrike Monitor project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Dependabot configuration for automated dependency updates
- Issue templates for bug reports and feature requests
- Pull request template
- Security policy (SECURITY.md)
- Code of Conduct
- Comprehensive changelog

### Changed
- Enhanced repository documentation and governance

### Security
- Implemented automated security scanning
- Added vulnerability reporting guidelines

## [1.0.0] - 2025-12-12

### Added
- Initial release of CrowdStrike Monitor
- Automated monitoring of CrowdStrike news and blog updates
- GitHub Actions-based scheduling
- No API key required for basic monitoring
- Python-based scraping and parsing

### Features
- Daily scheduled runs
- Automated issue creation for new updates
- RSS feed parsing
- Web scraping capabilities
